## Common Issues

| Phenomenon | Solution |
| --- | --- |
| **Connection Failed** | Check if Mihomo core is running, and carefully verify that the API address and Secret in `mihosh config show` match the ones in Mihomo's configuration file. |
| **Nodes Not Found** | Ensure Proxy Groups are correctly configured in Mihomo's configuration file. |
| **Test Timeout** | Increase the `timeout` value in the config, or change `test_url` to a faster local/regional address. |
| **Theme Not Applied** | Check if the configured `theme` name is spelled correctly (Supported: `tokyo-night`, `catppuccin`, `gruvbox`, `nord`, `dracula`). |
| **Garbled UI or Misaligned Tables** | Your terminal font might not support special characters. It is highly recommended to use a **Nerd Font**, or ensure your font supports CJK monospace characters well. |
| **Auto-refresh Not Working** | Check `auto_refresh_interval` in config. Setting it to `0` disables auto-refresh. |

## Quick Diagnostics

If you encounter weird errors, please run the diagnostics command first:
```bash
mihosh doctor
```
This command will automatically check your config file, connection status, and API compatibility, then output a report.
