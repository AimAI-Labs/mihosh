## Common Issues

| Phenomenon | Solution |
| --- | --- |
| **Connection Failed** | Check if Mihomo core is running, and carefully verify that the API address and Secret in `mihosh config show` match the ones in Mihomo's configuration file. |
| **Nodes Not Found** | Ensure Proxy Groups are correctly configured in Mihomo's configuration file. |
| **Test Timeout** | Increase the `timeout` value in the config, or change `test_url` to a faster local/regional address. |
| **Theme Not Applied** | Check if the configured `theme` name is spelled correctly (Supported: `tokyo-night`, `dark`, `light`, `solarized-dark`, `solarized-light`, `colorblind-dark`, `colorblind-light`, `terminal`, `catppuccin`, `catppuccin-latte`, `gruvbox`, `gruvbox-light`, `nord`, `dracula`, `kanagawa`, `one-dark`, `rose-pine`, `everforest`). |
| **Garbled UI or Misaligned Tables** | Your terminal font might not support special characters. It is highly recommended to use a **Nerd Font**, or ensure your font supports CJK monospace characters well. |
| **Auto-refresh Not Working** | Check `auto_refresh_interval` in config. Setting it to `0` disables auto-refresh. |
| **Linux TUN Fails (`CAP_NET_ADMIN`)** | Grant Linux capabilities to the Mihosh executable itself (not only `mihomo`): `sudo setcap cap_net_admin,cap_net_raw+ep /path/to/mihosh` (or `"$HOME/.mihosh/bin/mihosh"` in background service mode). Re-run `setcap` after replacing or upgrading the binary. See [`mihosh core`](/docs/commands/core#system-proxy-tun-and-recovery). |
| **System Proxy Unavailable (`gsettings`)** | Linux system proxy integration uses GNOME `gsettings`. On headless servers or non-GNOME desktops without `gsettings`, use shell proxy (`mihosh activate` / `mihosh proxy on`) or TUN instead. |

## Quick Diagnostics

If you encounter weird errors, please run the diagnostics command first:
```bash
mihosh doctor
```
This command will automatically check your config file, connection status, and API compatibility, then output a report.
