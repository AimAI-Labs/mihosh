---
title: "Mihomo API Reference"
description: List of RESTful APIs used by Mihosh
---

As a Mihomo client, Mihosh relies on its RESTful API for interaction. Below are the key endpoints used by Mihosh.

> **Note**: All HTTP and WS requests require `Authorization: Bearer <secret>` in the Header.

## Proxies

| Path | Method | Description |
| --- | --- | --- |
| `/proxies` | GET | Get all proxy groups and nodes |
| `/proxies/:group` | GET | Get specific proxy group info |
| `/proxies/:group` | PUT | Select a proxy node |
| `/proxies/:group/delay` | GET | Test node latency |
| `/group/:group/delay` | GET | Test all nodes in a group |

## Connections & Configs

| Path | Method | Description |
| --- | --- | --- |
| `/connections` | GET | Get connections list |
| `/connections` | DELETE | Close all connections |
| `/connections/:id` | DELETE | Close a specific connection |
| `/configs` | GET | Get current configuration |
| `/configs` | PATCH | Update configuration (e.g., mode switch) |
| `/version` | GET | Get Mihomo version |

## Rules

| Path | Method | Description |
| --- | --- | --- |
| `/rules` | GET | Get rules list |
| `/providers/rules` | GET | Get rule providers list |
| `/providers/rules/:name` | PUT | Update a specific rule provider |

## Real-time Data (WebSocket)

| Path | Method | Description |
| --- | --- | --- |
| `/traffic` | WS | Real-time traffic up/down speeds |
| `/logs` | WS | Real-time log stream |
| `/connections` | WS | Real-time connection changes |
| `/memory` | WS | Real-time memory usage |
