Welcome to contribute to Mihosh! Below is a guide for setting up your development environment.

## Prerequisites

- Go 1.25 or higher
- [mise](https://mise.jdx.dev/) (Optional, for environment management)

## Fetch & Build

```bash
# 1. Clone code
git clone https://github.com/AimAI-Labs/mihosh.git
cd mihosh

# 2. Install dependencies
go mod download

# 3. Build
make build
# Or: go build -o mihosh .
```

## Test & Check

The project uses standard Go test tools and is configured with a comprehensive Makefile:

```bash
# Run unit tests
make test

# Run full checks including formatting, static analysis, tests, and build
make check
```

## CI Verification

The project is configured with GitHub Actions. Every commit or Pull Request will trigger:
- Formatting
- Module verification
- Static analysis (go vet)
- Unit testing (go test)
- Build
- Lint
- CodeQL Vulnerability Analysis

## Injecting Version Info

Release builds usually inject version variables via `ldflags` at compile time:
```bash
go build -ldflags "-X github.com/AimAI-Labs/mihosh/internal/domain/model.Version=v1.0.0"
```
