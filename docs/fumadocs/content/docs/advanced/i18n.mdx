Mihosh supports full internationalization (i18n), automatically switching languages based on your environment.

## Supported Languages

- English (`en-US`)
- Simplified Chinese (`zh-CN`)

## Configuring Language

By default, Mihosh uses `go-locale` to read the OS language settings and automatically matches the appropriate language (configured as `auto`).

You can override automatic detection via command:
```bash
mihosh config set language en-US
```
Or:
```bash
mihosh config set language zh-CN
```
To revert to auto-detection:
```bash
mihosh config set language auto
```

## Implementation Details

The core implementation is located in `pkg/i18n`. To add a new language, simply add the corresponding dictionary file to this directory and register it; no business code modification is required.
