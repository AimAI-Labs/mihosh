Mihosh has a powerful built-in multi-theme engine, allowing you to freely switch themes based on your terminal and personal preferences.

## Built-in Themes

Currently, 5 preset themes are supported:
- **`tokyo-night`** (Default): Dark blue-gray background with high-saturation cool tones.
- **`catppuccin`**: Soft, low-contrast macaron color palette.
- **`gruvbox`**: Retro, warm dark theme.
- **`nord`**: Cool gray colors inspired by Nordic ice and snow.
- **`dracula`**: Classic purplish dark theme.

You can switch them via the settings page or command line:
```bash
mihosh config set theme catppuccin
```

## Semantic Color System

None of Mihosh's components hardcode colors. Instead, they fetch colors semantically via `theme.Current()`:
- `Foreground`, `Muted`, `Background`, `Surface`
- `Primary`, `Secondary`
- `Success`, `Warning`, `Danger`, `Info`, `Border`

### Latency Color Ladder

The latency test colors follow a strict ladder strategy:
- **< 100ms**: `Success` (Green)
- **100 - 300ms**: `Warning` (Yellow)
- **> 300ms**: `Danger` (Red)
