Mihosh has a powerful built-in multi-theme engine, allowing you to freely switch themes based on your terminal and personal preferences.

## Built-in Themes

Mihosh includes 18 built-in themes covering dark, light, colorblind-friendly, and native terminal palettes:

- **`tokyo-night`** (Default): Dark blue-gray background with high-saturation cool tones.
- **`dark`**: Neutral dark slate theme with crisp, balanced accents.
- **`light`**: Clean neutral light theme for light terminal backgrounds.
- **`solarized-dark`**: Classic Solarized dark teal background with balanced accents. [Solarized palette](https://ethanschoonover.com/solarized/)
- **`solarized-light`**: Classic Solarized light cream background with subdued accents. [Solarized palette](https://ethanschoonover.com/solarized/)
- **`colorblind-dark`**: Colorblind-friendly dark theme using an Okabe-Ito palette to distinguish statuses and latencies without red/green confusion.
- **`colorblind-light`**: Colorblind-friendly light theme using a high-contrast Okabe-Ito palette.
- **`terminal`**: Follows your host terminal's native ANSI 16 palette.
- **`catppuccin`**: Soft, low-contrast dark pastel palette (Mocha).
- **`catppuccin-latte`**: Soft light pastel palette (Latte).
- **`gruvbox`**: Retro, warm dark theme.
- **`gruvbox-light`**: Retro, warm light theme.
- **`nord`**: Cool gray colors inspired by Nordic ice and snow.
- **`dracula`**: Classic purplish dark theme.
- **`kanagawa`**: Muted colors of Kanagawa Wave. [Kanagawa palette](https://github.com/rebelot/kanagawa.nvim/blob/master/lua/kanagawa/colors.lua)
- **`one-dark`**: Classic Atom / VS Code One Dark palette.
- **`rose-pine`**: Soft, low-contrast dark rose-and-iris palette.
- **`everforest`**: Eye-friendly muted forest green dark theme.

You can open the interactive theme picker with live preview in the TUI Settings page, or switch via the command line:
```bash
mihosh config set theme catppuccin
```

In Settings, choose **Border style** to switch the interface between rounded and square borders. The border style applies to every theme.

```bash
mihosh config set border-style square
```

## Semantic Color System

None of Mihosh's components hardcode colors. Instead, they fetch colors semantically via `theme.Current()`:
- `Foreground`, `Muted`, `Background`, `Surface`
- `Primary`, `Secondary`
- `Success`, `Warning`, `Danger`, `Info`, `Border`

### Latency Color Ladder

The latency test colors follow a strict ladder strategy:
- **< 100ms**: `Success` (Green)
- **100 - 300ms**: `Warning` (Yellow)
- **> 300ms**: `Danger` (Red)
