## Why Mihosh?

Mihosh bridges the gap between command-line configuration and graphical management interfaces through a lightweight terminal UI interface. It has the following advantages:

- **Out of the box**: No tedious configuration is required, a single command automatically connects to the local or remote Mihomo service.
- **Full-featured control**: View traffic in real time, switch nodes, manage proxy groups, and modify core configuration, all in the terminal.
- **Efficient interaction**: Keyboard-driven TUI interface, supporting rich shortcut key operations, built for efficiency enthusiasts.
