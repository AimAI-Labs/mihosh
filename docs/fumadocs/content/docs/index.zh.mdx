## 为什么选择 Mihosh？

Mihosh 通过轻量级的终端 UI 界面，弥合了命令行配置与图形化管理界面之间的鸿沟。它具备以下优势：

- **开箱即用**：无需繁琐配置，一条命令即可自动连接到本地或远程的 Mihomo 服务。
- **全功能掌控**：实时查看流量、切换节点、管理代理组、修改核心配置，一切尽在终端。
- **高效交互**：键盘驱动的 TUI 界面，支持丰富的快捷键操作，专为效率至上者打造。
