## 说明

`mihosh version` 命令用于显示 Mihosh 的版本号、Git Commit 哈希与构建日期。也可以运行 `mihosh --version`（`-v`）快速查看版本号。

## 用法

```bash
mihosh version [flags]
```

## 选项

| 选项 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | 输出格式，支持 `plain`、`table`、`json` |

## 示例

```bash
mihosh version
mihosh version -o table
mihosh version -o json
```
