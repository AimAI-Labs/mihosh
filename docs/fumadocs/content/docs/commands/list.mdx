---
title: "mihosh list"
description: List all proxy groups and node information.
---

The `mihosh list` command lists all proxy groups and their node information in the current configuration.

## Usage

```bash
mihosh list [flags]
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | Output format, supports `plain`, `table`, `json` |

## Examples

### Default Plain Output

```bash
mihosh list
```

### Output as Table

```bash
mihosh list -o table
```

### Output as JSON

Ideal for use with other tools (e.g., `jq`):

```bash
mihosh list -o json

# Filter for a specific proxy group using jq
mihosh list -o json | jq '.groups[] | select(.name == "Proxy")'
```

### Using Custom Configuration Directory

```bash
MIHOSH_CONFIG_DIR="$HOME/.mihosh-work" mihosh list
```
