## 说明

`mihosh config` 提供用于查看、修改与交互式编辑 Mihosh / Mihomo 配置的子命令。

## 环境变量

`MIHOSH_CONFIG_DIR` 指定 Mihosh 的配置根目录（必须为绝对路径）。配置、订阅、备份与托管内核运行文件均位于此目录。未设置或为空时默认使用 `~/.mihosh`。

```bash
export MIHOSH_CONFIG_DIR="$HOME/.mihosh-work"
mihosh config show
```

```powershell
$env:MIHOSH_CONFIG_DIR = Join-Path $env:USERPROFILE '.mihosh-work'
mihosh config show
```

## 子命令

### `show`

显示当前 Mihosh 配置以及自动发现的 Mihomo 连接信息（`external-controller`、脱敏后的 `secret`、`mixed-port`、代理 URL 与 Mihomo 配置文件路径）。

| 选项 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | 输出格式，支持 `plain`、`table`、`json` |

### `set <key> <value>`

设置单个 Mihosh 应用配置项。

- 用法：`mihosh config set <key> <value>`
- 支持的配置项：
  - `test_url` / `test-url`：测速目标 URL
  - `timeout`：请求与测速超时（毫秒）
  - `language`：`auto`、`zh-CN` 或 `en-US`
  - `auto_refresh_interval` / `auto-refresh-interval`：自动刷新间隔（秒，`>= 0`）
  - `theme`：界面主题名称（如 `tokyo-night`、`catppuccin`、`gruvbox`、`nord`、`dracula` 等）
  - `border_style` / `border-style`：边框风格，`rounded`（圆角）或 `square`（直角）

### `edit`

打开交互式选择器，在外部编辑器中编辑 Mihosh 或 Mihomo 配置文件；保存后自动校验语法，修改 Mihomo 配置时自动热重载内核。

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `--editor` | `$VISUAL` / `$EDITOR` / 自动检测 | 指定编辑器（如 `vim`、`nano`、`code`） |
| `--path` | 自动发现 | 显式指定 Mihomo 配置文件或目录路径 |

## 示例

```bash
mihosh config show
mihosh config show -o table
mihosh config show -o json
mihosh config set theme gruvbox
mihosh config set border-style square
mihosh config edit --editor vim
```
