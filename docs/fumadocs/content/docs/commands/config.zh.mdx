## 说明

`mihosh config` 提供了一组用于管理 Mihosh 配置的子命令。

## 子命令

### init

交互式初始化配置文件。
- 选项：`--force, -f` 覆盖已存在的配置。

### set

设置指定的配置项。
- 用法：`mihosh config set <key> <value>`
- 支持的 key：`test-url`, `timeout`, `theme`, `language`, `auto-refresh-interval`

### show

显示当前完整的配置信息。
- 选项：`--output, -o` 输出格式 (`text`, `json`, `table`)。

## 示例

```bash
mihosh config init -f
mihosh config set theme gruvbox
mihosh config show -o table
```
