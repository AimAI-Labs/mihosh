## 说明

`mihosh config` 提供了一组用于管理 Mihosh 配置的子命令。

## 环境变量

`MIHOSH_CONFIG_DIR` 指定 Mihosh 的配置根目录。值必须是绝对路径。配置、订阅、备份和托管内核运行文件都使用此目录。未设置或设为空时使用 `~/.mihosh`。

```bash
export MIHOSH_CONFIG_DIR="$HOME/.mihosh-work"
mihosh config show
```

```powershell
$env:MIHOSH_CONFIG_DIR = Join-Path $env:USERPROFILE '.mihosh-work'
mihosh config show
```

## 子命令

### init

交互式初始化配置文件。
- 选项：`--force, -f` 覆盖已存在的配置。

### set

设置指定的配置项。
- 用法：`mihosh config set <key> <value>`
- 支持的 key：`test-url`, `timeout`, `theme`, `language`, `auto-refresh-interval`

### show

显示当前完整的配置信息。
- 选项：`--output, -o` 输出格式 (`text`, `json`, `table`)。

## 示例

```bash
mihosh config init -f
mihosh config set theme gruvbox
mihosh config show -o table
```
