## 说明

`mihosh connections` 命令用于列出当前所有活跃连接，以及累计上传与下载流量。

## 用法

```bash
mihosh connections [flags]
```

## 选项

| 选项 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | 输出格式，支持 `plain`、`table`、`json` |

## 示例

```bash
mihosh connections
mihosh connections -o table
mihosh connections -o json
```
