## Description

The `mihosh status` command displays a snapshot of the running Mihomo core, including current proxy mode, active connection count, real-time upload/download speeds, memory usage, and active nodes for `GLOBAL` / `Proxy` groups.

## Usage

```bash
mihosh status [flags]
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | Output format, supports `plain`, `table`, `json` |

## Examples

```bash
mihosh status
mihosh status -o table
mihosh status -o json
```
