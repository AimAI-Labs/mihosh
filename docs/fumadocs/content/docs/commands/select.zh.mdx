---
title: mihosh select
description: 切换代理组中的活跃节点。
---

`mihosh select` 命令用于在指定代理组中切换活跃节点。

## 用法

```bash
mihosh select <group> <node>
```

## 参数

| 参数 | 说明 |
| --- | --- |
| `<group>` | 代理组名称，例如 `Proxy`、`Auto` 等 |
| `<node>` | 目标节点名称，需为该代理组中的有效节点 |

## 示例

### 切换到指定节点

```bash
mihosh select Proxy "香港 01"
```

### 节点名称包含空格

当节点名称包含空格时，需要使用引号包裹：

```bash
mihosh select Proxy "US - Los Angeles"
```

### 配合 list 命令使用

先查看可用的代理组和节点，再进行切换：

```bash
# 查看所有代理组和节点
mihosh list

# 切换到目标节点
mihosh select "节点选择" "日本 01"
```

<Callout type="warn">
如果指定的代理组不存在或节点名称不在该组中，命令将返回错误提示。
</Callout>
