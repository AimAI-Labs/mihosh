---
title: "mihosh test"
description: Test the current active node or measure latency of a node or proxy group.
---

The `mihosh test` command tests the currently selected proxy node (including exit IP, country/region, city, ASN, and organization) or measures latency for a specific node or proxy group.

## Usage

```bash
mihosh test [node <name> | group <name>] [flags]
```

## Modes

### Test Current Active Node

Without arguments, tests the currently selected proxy node and prints its proxy chain and exit IP details:

```bash
mihosh test
```

### Test Specific Node

Test latency for a single node by name:

```bash
mihosh test node <name>
```

### Test Proxy Group

Test latency for all nodes in a proxy group:

```bash
mihosh test group <name>
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | Output format, supports `plain`, `table`, `json` |

## Examples

```bash
# Test current active node and exit IP info
mihosh test

# Test latency of a specific node
mihosh test node "Hong Kong 01"

# Test an entire proxy group
mihosh test group Proxy

# Display results as a table or JSON
mihosh test group Proxy -o table
mihosh test -o json
```

<Callout type="info">
The latency test URL and timeout can be configured via `mihosh config set test_url <url>` and `mihosh config set timeout <ms>`.
</Callout>
