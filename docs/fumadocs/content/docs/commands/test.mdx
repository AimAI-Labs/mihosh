---
title: "mihosh test"
description: Perform latency tests on proxy nodes.
---

The `mihosh test` command performs latency testing on proxy nodes to help you understand the network quality of each node.

## Usage

```bash
mihosh test [command] [flags]
```

## Subcommands

### Test Current Node

Without subcommands, tests the currently selected proxy node:

```bash
mihosh test
```

### Test Specific Node

Use the `node` subcommand to test a node by name:

```bash
mihosh test node <name>
```

### Test Proxy Group

Use the `group` subcommand to test all nodes within a proxy group:

```bash
mihosh test group <name>
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `text` | Output format, supports `text`, `json`, `table` |

## Examples

### Test Current Node

```bash
mihosh test
```

### Test Latency of Specific Node

```bash
mihosh test node "Hong Kong 01"
```

### Test Entire Proxy Group

```bash
mihosh test group Proxy
```

### Display Results as Table

```bash
mihosh test group Proxy -o table
```

### Output in JSON Format

```bash
mihosh test group Proxy -o json
```

<Callout type="info">
The target URL and timeout for latency testing can be configured via the `mihosh config set` command.
</Callout>
