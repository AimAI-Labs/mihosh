## Description

The `mihosh connections` command lists all currently active connections together with total upload and download traffic.

## Usage

```bash
mihosh connections [flags]
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | Output format, supports `plain`, `table`, `json` |

## Examples

```bash
mihosh connections
mihosh connections -o table
mihosh connections -o json
```
