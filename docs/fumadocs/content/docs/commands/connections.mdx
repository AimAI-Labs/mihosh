title: "mihosh connections"
description: View active connections
---

## Description

The `mihosh connections` command lists all currently active proxy connections.

## Options

- `--output, -o`: Output format, supports `text`, `json`, `table` (Default: `text`).
- `--limit, -l`: Maximum number of connections to display (Default: `20`).

## Examples

```bash
mihosh connections
mihosh connections -o table -l 50
```
