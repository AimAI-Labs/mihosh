---
title: "mihosh list"
description: List all proxy groups and node information.
---

The `mihosh list` command lists all proxy groups and their node information in the current configuration.

## Usage

```bash
mihosh list [flags]
```

## Options

| Option | Shorthand | Default | Description |
| --- | --- | --- | --- |
| `--output` | `-o` | `text` | Output format, supports `text`, `json`, `table` |

## Examples

### Default Text Output

```bash
mihosh list
```

### Output as Table

```bash
mihosh list -o table
```

### Output as JSON

Ideal for use with other tools (e.g., `jq`):

```bash
mihosh list -o json

# Filter for a specific proxy group using jq
mihosh list -o json | jq '.[] | select(.name == "Proxy")'
```

### Using Custom Configuration

```bash
mihosh list -c ~/.config/mihosh/custom.toml
```
