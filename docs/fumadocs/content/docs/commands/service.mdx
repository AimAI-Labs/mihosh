## Description

The `mihosh service <action>` command manages Mihomo's systemd service on Linux systems.

## Supported Actions

- `status`: View service status
- `start`: Start service
- `stop`: Stop service
- `restart`: Restart service
- `enable`: Enable service on boot
- `disable`: Disable service on boot

## Examples

```bash
mihosh service status
mihosh service restart
```
