---
title: "mihosh mode"
description: Query or switch Mihomo proxy mode.
---

## Description

The `mihosh mode` command displays the current proxy mode when called without arguments, or switches Mihomo's proxy mode when a mode is specified.

## Usage

```bash
mihosh mode [rule|global|direct]
```

## Supported Modes

- `rule`: Rule mode, routing based on configured rules.
- `global`: Global mode, all traffic goes through the global proxy node.
- `direct`: Direct mode, all traffic connects directly, bypassing the proxy.

## Examples

```bash
# Show current mode
mihosh mode

# Switch proxy mode
mihosh mode rule
mihosh mode global
mihosh mode direct
```
