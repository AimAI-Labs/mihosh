---
title: mihosh completion
description: 为 Bash、Zsh、Fish 或 PowerShell 生成终端自动补全脚本。
---

## 用法

```bash
mihosh completion <bash|zsh|fish|powershell>
```

## 说明

为指定 shell（`bash`、`zsh`、`fish`、`powershell`）生成命令行自动补全脚本。

## 示例配置

### Bash

```bash
# 加载到当前会话
source <(mihosh completion bash)

# 在 Linux 上全局安装
mihosh completion bash | sudo tee /etc/bash_completion.d/mihosh > /dev/null
```

### Zsh

```zsh
# 安装到 fpath 目录
mkdir -p ~/.zsh/completions
mihosh completion zsh > ~/.zsh/completions/_mihosh
# 在 ~/.zshrc 中添加：
#   fpath=(~/.zsh/completions $fpath)
#   autoload -Uz compinit && compinit
```

### Fish

```fish
mihosh completion fish | source

# 永久安装
mihosh completion fish > ~/.config/fish/completions/mihosh.fish
```

### PowerShell

```powershell
# 加载到当前会话
mihosh completion powershell | Out-String | Invoke-Expression

# 永久安装
mihosh completion powershell >> $PROFILE
```
