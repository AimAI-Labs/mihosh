---

## Description

The `mihosh mode <mode>` command switches Mihomo's proxy mode.

## Supported Modes

- `rule`: Rule mode, routing based on configured rules.
- `global`: Global mode, all traffic goes through the global proxy node.
- `direct`: Direct mode, all traffic connects directly, bypassing the proxy.

## Examples

```bash
mihosh mode rule
mihosh mode global
```
