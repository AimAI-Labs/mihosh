---
title: mihosh activate 与 proxy
description: 在 Bash 或 Zsh 中管理 Mihomo 代理
---

先加载保存的终端代理设置，再在当前 shell 使用 `mihosh proxy`。Zsh 用户将 `bash` 换成 `zsh`。

```bash
eval "$(mihosh activate bash)"
mihosh proxy on
mihosh proxy test --output table
mihosh proxy off
```

`on` 和 `off` 切换当前 shell 的代理变量。代理地址取自 Mihomo 的 mixed-port，同时支持大小写两组代理环境变量。

`proxy test` 通过已配置的 Mihomo 代理查询两个 IP 数据源，逐项显示出口 IP、延迟和错误。`--output json` 可输出供脚本读取的结果。 [IP.SB API](https://ip.sb/api/) · [ipify API](https://www.ipify.org/)

在 TUI 的 **Core → 高级设置 → 终端代理环境** 按 `w` 切换偏好。Mihosh 会将初始化命令写入 Bash 的 `~/.bashrc` 或 Zsh 的 `${ZDOTDIR:-$HOME}/.zshrc`。重新打开或刷新 shell 后生效。重复保存会更新已有的 Mihosh 区块，并保留文件中的其他设置。移动可执行文件后可重新保存以更新路径。

现有脚本仍可使用 `mihosh env`、`mihosh on` 和 `mihosh off`。
