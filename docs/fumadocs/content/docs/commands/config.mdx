## Description

`mihosh config` provides a set of subcommands for managing Mihosh configurations.

## Subcommands

### init

Interactively initialize the configuration file.
- Options: `--force, -f` Overwrite existing configuration.

### set

Set a specific configuration item.
- Usage: `mihosh config set <key> <value>`
- Supported keys: `test-url`, `timeout`, `theme`, `language`, `auto-refresh-interval`

### show

Display the complete current configuration information.
- Options: `--output, -o` Output format (`text`, `json`, `table`).

## Examples

```bash
mihosh config init -f
mihosh config set theme gruvbox
mihosh config show -o table
```
