---
title: mihosh list
description: 列出所有代理组及节点信息。
---

`mihosh list` 命令用于列出当前配置中的所有代理组及其节点信息。

## 用法

```bash
mihosh list [flags]
```

## 选项

| 选项 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | 输出格式，支持 `plain`、`table`、`json` |

## 示例

### 默认纯文本输出

```bash
mihosh list
```

### 以表格形式输出

```bash
mihosh list -o table
```

### 以 JSON 格式输出

适合配合其他工具（如 `jq`）进行脚本处理：

```bash
mihosh list -o json

# 使用 jq 过滤特定代理组
mihosh list -o json | jq '.groups[] | select(.name == "Proxy")'
```

### 指定自定义配置目录

```bash
MIHOSH_CONFIG_DIR="$HOME/.mihosh-work" mihosh list
```
