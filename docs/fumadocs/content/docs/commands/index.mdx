Mihosh provides a comprehensive command-line interface, allowing you to manage the Mihomo proxy core, subscriptions, backups, DNS diagnostics, and shell proxy integration without opening the TUI.

## Command Overview

| Command | Description |
| --- | --- |
| `mihosh` | Start the interactive TUI |
| `mihosh list` | List proxy groups and nodes |
| `mihosh select` | Switch active node in a proxy group |
| `mihosh test` | Test current exit node or latency of a node / group |
| `mihosh connections` | View active connections |
| `mihosh mode` | Query or switch proxy mode (`rule` / `global` / `direct`) |
| `mihosh status` | View Mihomo core status |
| `mihosh dns` | Query DNS records via Mihomo `/dns/query` |
| `mihosh core` / `mihosh setup` | Managed core installation, lifecycle, background service, system proxy, and TUN |
| `mihosh config` | Show, set, or edit Mihosh / Mihomo configuration |
| `mihosh sync` | Local archive backup/restore and PostgreSQL cloud sync |
| `mihosh service` | Manage systemd service and view logs (Linux) |
| `mihosh doctor` | Configuration and connectivity health check |
| `mihosh activate` / `mihosh proxy` | Shell proxy activation, `on`/`off` toggle, and exit IP probe (plus legacy `on`/`off`/`env`) |
| `mihosh completion` | Generate shell completion scripts (`bash`, `zsh`, `fish`, `powershell`) |
| `mihosh version` | Show Mihosh version, commit, and build date |

## Output Formats & Environment

Most query and management commands support `--output` / `-o` with `plain`, `table`, or `json` for interactive reading or scripting.

To use an isolated configuration directory instead of the default `~/.mihosh`, set the `MIHOSH_CONFIG_DIR` environment variable to an absolute path:

```bash
MIHOSH_CONFIG_DIR="$HOME/.mihosh-work" mihosh list --output json
```

## Exit Codes

| Exit Code | Meaning |
| --- | --- |
| `0` | Success |
| `1` | General error |
| `2` | Invalid command arguments or flags |
| `3` | Configuration error |
| `4` | Network, API, or health-check error |
