Mihosh 提供了丰富的命令行接口，让你无需打开 TUI 界面即可快速管理 Mihomo 代理核心。

## 命令一览

| 命令 | 说明 |
| --- | --- |
| `mihosh` | 启动交互式 TUI 界面 |
| `mihosh list` | 列出代理组和节点 |
| `mihosh select` | 切换代理节点 |
| `mihosh test` | 延迟测试 |
| `mihosh connections` | 查看活跃连接 |
| `mihosh mode` | 切换代理模式 |
| `mihosh status` | 查看 Mihomo 核心状态 |
| `mihosh config` | 配置管理 |
| `mihosh service` | systemd 服务管理 |
| `mihosh doctor` | 配置健康检查 |
| `mihosh on/off` | 开启/关闭系统代理 |
| `mihosh selfupdate` | 自动更新 |
| `mihosh version` | 版本信息 |

## 全局选项

所有命令均支持以下全局选项：

```bash
mihosh <command> --config, -c <path>
```

使用 `--config`（或简写 `-c`）可以指定自定义的配置文件路径。当你有多套配置需要切换时，这个选项尤为实用：

```bash
# 使用自定义配置文件
mihosh list -c ~/.config/mihosh/custom.toml

# 等价写法
mihosh list --config ~/.config/mihosh/custom.toml
```

<Callout type="info">
如果不指定 `--config`，Mihosh 将使用默认路径下的配置文件。
</Callout>
