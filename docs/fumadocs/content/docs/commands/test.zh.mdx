---

`mihosh test` 命令用于测试当前生效代理节点（输出节点链、出口 IP、国家/地区、城市、ASN 与组织），或对指定节点、策略组进行延迟测速。

## 用法

```bash
mihosh test [node <节点名> | group <策略组名>] [flags]
```

## 子模式

### 测试当前生效节点

不带参数时，验证当前选中节点并查询代理链路与出口 IP 信息：

```bash
mihosh test
```

### 测试指定节点

使用 `node` 测试单个节点的延迟：

```bash
mihosh test node <节点名>
```

### 测试整个策略组

使用 `group` 对代理组内的所有节点进行测速：

```bash
mihosh test group <策略组名>
```

## 选项

| 选项 | 简写 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--output` | `-o` | `plain` | 输出格式，支持 `plain`、`table`、`json` |

## 示例

```bash
# 测试当前生效节点及出口 IP
mihosh test

# 测试指定节点延迟
mihosh test node "香港 01"

# 测试整个策略组
mihosh test group Proxy

# 以表格或 JSON 格式输出
mihosh test group Proxy -o table
mihosh test -o json
```

<Callout type="info">
测速目标 URL 和超时时间可通过 `mihosh config set test_url <url>` 和 `mihosh config set timeout <ms>` 修改。
</Callout>
