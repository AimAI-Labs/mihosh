Mihosh 是一款基于 Mihomo 的全功能终端 UI (TUI) 与 CLI 代理管理工具，既支持连接已有 Mihomo 实例，也支持内置托管内核一条龙配置。

## 快速步骤

<Steps>
  <Step>
    ### 安装 Mihosh
    请参考 [安装指南](/docs/getting-started/installation) 将 Mihosh 安装到你的系统中。
  </Step>

  <Step>
    ### 初始化托管内核或连接已有 Mihomo
    如需由 Mihosh 自动安装托管内核并生成基础配置，可执行：
    ```bash
    mihosh setup
    ```
    如果本机已在运行 Mihomo，Mihosh 会自动发现其配置文件中的 `external-controller`、`secret` 和 `mixed-port`，也可以运行 `mihosh doctor` 检查连通性。
  </Step>

  <Step>
    ### 启动应用
    只需在终端输入：
    ```bash
    mihosh
    ```
  </Step>
</Steps>
