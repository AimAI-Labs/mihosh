The configuration file for Mihosh is stored in `~/.mihosh/config.yaml` by default. When running `mihosh` for the first time, if the configuration file does not exist, the system will automatically generate a configuration with default values.

## Initialize Configuration

You can quickly initialize or reset the configuration through interactive commands:

```bash
mihosh config init
```
This command will prompt you to enter the Mihomo API address, port, and secret.

<Callout title="Hint" type="info">
  If your Mihomo core does not have an authentication secret set, simply press Enter to leave it blank when prompted for the secret.
</Callout>

## Configuration Items Reference

Here are all the configuration items supported by Mihosh:

| Configuration Item | Type | Description | Default Value |
| --- | --- | --- | --- |
| `server.host` | string | Mihomo API address | `127.0.0.1` |
| `server.port` | int | Mihomo API port | `9090` |
| `server.secret` | string | API secret | `""` |
| `test_url` | string | Latency test URL | `http://www.gstatic.com/generate_204` |
| `timeout` | int | Test timeout (ms) | `5000` |
| `language` | string | Interface language | `auto` (Supports: `auto`, `en-US`, `zh-CN`) |
| `auto_refresh_interval` | int | Auto refresh interval (seconds) | `5` |
| `theme` | string | UI theme | `tokyo-night` |

## Command Line Configuration Management

In addition to manually modifying the file, you can also use command-line tools directly to quickly modify or view configuration items, which is very useful when writing automation scripts:

```bash
mihosh config set theme catppuccin
mihosh config set language zh-CN
mihosh config show
```

```yaml title="~/.mihosh/config.yaml"
language: auto
subs:
  - uid: c37c7c25
    name: fn
    source:
      kind: 0
      url: https://xx.xx.xx.xx/subscribe?token=1a3b3a4
      path: ""
    updated_at: 0
  - uid: 2fb6a0dc
    name: tf
    source:
      kind: 0
      url: https://xx.x.x.xx/subscribe?token=f47f9
      path: ""
    updated_at: 0
test_url: http://www.gstatic.com/generate_204
theme: tokyo-night
timeout: 4000
```
