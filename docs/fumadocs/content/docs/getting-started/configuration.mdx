The configuration file for Mihosh is stored in `~/.mihosh/config.yaml` by default (or `$MIHOSH_CONFIG_DIR/config.yaml` when `MIHOSH_CONFIG_DIR` is set to an absolute path). When running `mihosh` for the first time, default values are used automatically and Mihomo connection settings (`external-controller`, `secret`, `mixed-port`) are discovered from your Mihomo configuration.

## Quick Setup & Editing

On Linux and Windows, install a Mihomo core and create a baseline managed configuration with the CLI:

```bash
mihosh setup
```

On macOS, start Mihomo separately. Use its external controller from Mihosh and check the connection with `mihosh doctor`.

To inspect or interactively edit Mihosh / Mihomo configuration files:

```bash
mihosh config show
mihosh config edit
```

<Callout title="Hint" type="info">
  When editing Mihomo's configuration with `mihosh config edit`, Mihosh validates the YAML syntax on save and automatically hot-reloads the running Mihomo core.
</Callout>

## Configuration Items Reference

Here are the main application preferences in `~/.mihosh/config.yaml` that can be updated via `mihosh config set`:

| Configuration Item | CLI Key | Type | Description | Default Value |
| --- | --- | --- | --- | --- |
| `test_url` | `test_url` / `test-url` | string | Latency test URL | `http://www.gstatic.com/generate_204` |
| `timeout` | `timeout` | int | Test/API timeout (ms) | `5000` |
| `language` | `language` | string | Interface language (`auto`, `en-US`, `zh-CN`) | `auto` |
| `auto_refresh_interval` | `auto_refresh_interval` / `auto-refresh-interval` | int | Auto refresh interval in seconds (`0` disables) | `5` |
| `theme` | `theme` | string | UI theme name | `tokyo-night` |
| `border_style` | `border_style` / `border-style` | string | Panel border style (`rounded`, `square`) | `rounded` |

## Command Line Configuration Management

You can quickly view or modify preferences from the CLI for automation and scripting:

```bash
mihosh config set theme catppuccin
mihosh config set language zh-CN
mihosh config set border-style square
mihosh config show -o table
```

## Environment Variables

| Variable | Description |
| --- | --- |
| `MIHOSH_CONFIG_DIR` | Absolute path to override the default `~/.mihosh` configuration and data root |
| `MIHOSH_SYNC_PG_DSN` | Default PostgreSQL DSN for `mihosh sync push/pull/status` |
| `MIHOSH_SYNC_KEY` | Default profile key for `mihosh sync push/pull/status` |

## Complete Configuration Example

```yaml title="~/.mihosh/config.yaml"
active_sub: c37c7c25
auto_refresh_interval: 5
border_style: rounded
language: auto
subs:
  - uid: c37c7c25
    name: fn
    source:
      kind: 0
      url: https://example.com/subscribe?token=redacted
      path: ""
    updated_at: 0
test_url: http://www.gstatic.com/generate_204
theme: tokyo-night
timeout: 4000
```
