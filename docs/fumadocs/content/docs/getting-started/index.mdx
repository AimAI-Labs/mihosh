Mihosh is a full-featured Terminal UI (TUI) and CLI management tool for Mihomo. It works both with an existing Mihomo instance and in standalone managed-core mode.

## Quick Steps

<Steps>
  <Step>
    ### Install Mihosh
    Please refer to the [Installation Guide](/docs/getting-started/installation) to install Mihosh on your system.
  </Step>

  <Step>
    ### Set Up Core or Connect Existing Mihomo
    On Linux and Windows, Mihosh can install and manage a Mihomo core automatically:
    ```bash
    mihosh setup
    ```
    On macOS, start Mihomo separately and connect to its external controller. For a local instance, Mihosh auto-discovers its configuration (`external-controller`, `secret`, `mixed-port`). Run `mihosh doctor` to verify connectivity.
  </Step>

  <Step>
    ### Start the Application
    Simply type in the terminal:
    ```bash
    mihosh
    ```
  </Step>
</Steps>
