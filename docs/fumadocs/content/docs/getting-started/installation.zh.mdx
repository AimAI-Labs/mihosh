Mihosh 支持 Linux 和 macOS 系统 (amd64 和 arm64 架构)。

## 安装方法

我们提供多种安装方式，请根据你的系统环境选择最适合的一种：

<Tabs items={['脚本安装 (推荐)', 'Homebrew (macOS)', '源码编译']}>
  <Tab value="脚本安装 (推荐)">
    在 Linux 或 macOS 终端中运行以下一键安装脚本：
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AimAI-Labs/mihosh/refs/heads/main/install.sh | bash
    ```
  </Tab>
  <Tab value="Homebrew (macOS)">
    如果你是 macOS 用户，并使用 Homebrew 包管理器，可以通过以下命令安装：
    ```bash
    brew tap AimAI-Labs/mihosh https://github.com/AimAI-Labs/mihosh
    brew install mihosh
    ```
  </Tab>
  <Tab value="源码编译">
    要求你的系统中已安装 Go 1.25+：
    ```bash
    git clone https://github.com/AimAI-Labs/mihosh.git
    cd mihosh
    make build
    # 编译后的二进制文件位于当前目录的 mihosh
    ```
  </Tab>
</Tabs>

## 验证安装

安装完成后，可以通过以下命令验证是否安装成功：

```bash
mihosh version
```
