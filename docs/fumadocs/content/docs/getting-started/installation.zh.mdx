Mihosh 支持 Linux 和 macOS 系统 (amd64 和 arm64 架构)。

## 版本通道：稳定版（`main`）与开发版（`dev`）

| 通道 | 分支 | 标签格式 | 安装方式 | 自动更新行为 | 适用对象 |
| --- | --- | --- | --- | --- | --- |
| **稳定版** | `main` | `vX.Y.Z` | 一键脚本（`install.sh`）、Homebrew、GitHub Latest Release、`main` 源码编译 | 仅检查并升级到正式版（`vX.Y.Z`），自动忽略预发布版 | 绝大多数日常用户 |
| **开发版** | `dev` | `vX.Y.Z-alpha.N` / `-beta.N` / `-rc.N` | GitHub 预发布版压缩包、`dev` 源码编译 | 预发布版不会覆盖 Homebrew Formula，也不会推送给稳定版用户 | 贡献者与尝鲜测试用户 |

## 安装稳定版（`main`）

我们为稳定版提供多种安装方式，请根据你的系统环境选择最适合的一种：

<Tabs items={['脚本安装 (推荐)', 'Homebrew (macOS / Linux)', '源码编译']}>
  <Tab value="脚本安装 (推荐)">
    在 Linux 或 macOS 终端中运行以下一键安装脚本：
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AimAI-Labs/mihosh/refs/heads/main/install.sh | bash
    ```
  </Tab>
  <Tab value="Homebrew (macOS / Linux)">
    如果你在 macOS 或 Linux 上使用 Homebrew 包管理器，可以通过以下命令安装：
    ```bash
    brew tap AimAI-Labs/mihosh https://github.com/AimAI-Labs/mihosh
    brew trust AimAI-Labs/mihosh # Homebrew 6+ 需要先信任第三方 tap
    brew install AimAI-Labs/mihosh/mihosh
    ```
  </Tab>
  <Tab value="源码编译">
    要求你的系统中已安装 Go 1.25+：
    ```bash
    git clone --branch main https://github.com/AimAI-Labs/mihosh.git
    cd mihosh
    make build
    # 编译后的二进制文件位于当前目录的 mihosh
    ```
  </Tab>
</Tabs>

## 安装开发版与预发布版（`dev`）

如果你希望提前体验最新特性或测试预发布版本（`vX.Y.Z-rc.N` / `-beta.N` / `-alpha.N`），可以通过以下方式获取：

1. **下载预发布版压缩包：** 前往 [GitHub Releases](https://github.com/AimAI-Labs/mihosh/releases) 选择带有预发布标记的版本，下载对应系统架构的 `.tar.gz` 解压后放入 `PATH`。
2. **从 `dev` 分支源码编译**（要求已安装 Go 1.25+）：
   ```bash
   git clone --branch dev https://github.com/AimAI-Labs/mihosh.git
   cd mihosh
   make build
   # 编译后的二进制文件位于当前目录的 mihosh
   ```

## 验证安装

安装完成后，可以通过以下命令验证是否安装成功：

```bash
mihosh version
```

## 卸载 Mihosh

Mihosh 内置一键卸载功能，可自动停止托管内核与后台服务、清理 shell 代理配置，并支持选择是否保留配置与订阅数据：

```bash
# 交互式卸载（可选择是否保留配置）
mihosh uninstall

# 非交互卸载并保留配置目录（~/.mihosh 或 $MIHOSH_CONFIG_DIR）
mihosh uninstall --yes --keep-config
```

也可以在 TUI 的 **设置（Settings）** 页面按 `u` 打开卸载确认弹窗。如果是通过 Homebrew 安装，在清理配置与服务后执行 `brew uninstall mihosh` 即可。
