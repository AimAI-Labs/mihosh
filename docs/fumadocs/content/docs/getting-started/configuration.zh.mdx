Mihosh 的配置文件默认存储在 `~/.mihosh/config.yaml`（若设置了绝对路径环境变量 `MIHOSH_CONFIG_DIR`，则位于 `$MIHOSH_CONFIG_DIR/config.yaml`）。首次运行 `mihosh` 时会自动使用默认配置，并从 Mihomo 配置文件自动发现 `external-controller`、`secret` 与 `mixed-port`。

## 快速初始化与编辑

在 Linux 和 Windows 上，可通过 CLI 安装托管内核并生成基础配置：

```bash
mihosh setup
```

在 macOS 上，请单独启动 Mihomo，再在 Mihosh 中连接其外部控制器。可运行 `mihosh doctor` 检查连通性。

查看或交互式编辑 Mihosh / Mihomo 配置文件：

```bash
mihosh config show
mihosh config edit
```

<Callout title="提示" type="info">
  使用 `mihosh config edit` 编辑 Mihomo 配置后，Mihosh 会自动校验 YAML 语法并在内容变化时热重载 Mihomo 内核。
</Callout>

## 配置项参考

以下是 `~/.mihosh/config.yaml` 中可通过 `mihosh config set` 修改的主要应用偏好配置：

| 配置项 | CLI Key | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- | --- |
| `test_url` | `test_url` / `test-url` | string | 延迟测试 URL | `http://www.gstatic.com/generate_204` |
| `timeout` | `timeout` | int | 测速与请求超时（毫秒） | `5000` |
| `language` | `language` | string | 界面语言（`auto`、`en-US`、`zh-CN`） | `auto` |
| `auto_refresh_interval` | `auto_refresh_interval` / `auto-refresh-interval` | int | 自动刷新间隔（秒，`0` 为关闭） | `5` |
| `theme` | `theme` | string | 界面主题名称 | `tokyo-night` |
| `border_style` | `border_style` / `border-style` | string | 边框风格（`rounded`、`square`） | `rounded` |

## 命令行配置管理

你也可以直接通过命令行快速修改或查看配置项，便于脚本化操作：

```bash
mihosh config set theme catppuccin
mihosh config set language zh-CN
mihosh config set border-style square
mihosh config show -o table
```

## 环境变量

| 变量名 | 说明 |
| --- | --- |
| `MIHOSH_CONFIG_DIR` | 指定绝对路径以覆盖默认的 `~/.mihosh` 配置与数据根目录 |
| `MIHOSH_SYNC_PG_DSN` | `mihosh sync push/pull/status` 默认使用的 PostgreSQL DSN |
| `MIHOSH_SYNC_KEY` | `mihosh sync push/pull/status` 默认使用的云端配置键名 |

## 完整配置示例

```yaml title="~/.mihosh/config.yaml"
active_sub: c37c7c25
auto_refresh_interval: 5
border_style: rounded
language: auto
subs:
  - uid: c37c7c25
    name: fn
    source:
      kind: 0
      url: https://example.com/subscribe?token=redacted
      path: ""
    updated_at: 0
test_url: http://www.gstatic.com/generate_204
theme: tokyo-night
timeout: 4000
```
