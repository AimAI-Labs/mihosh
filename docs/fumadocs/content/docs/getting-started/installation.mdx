Mihosh supports Linux and macOS systems (amd64 and arm64 architectures).

## Release Channels: Stable (`main`) vs Development (`dev`)

| Channel | Branch | Tag Format | Install Methods | Auto-Update Behavior | Audience |
| --- | --- | --- | --- | --- | --- |
| **Stable** | `main` | `vX.Y.Z` | Script (`install.sh`), Homebrew, GitHub Latest Release, source on `main` | Checks and applies stable releases (`vX.Y.Z`); ignores prereleases | General users |
| **Development** | `dev` | `vX.Y.Z-alpha.N` / `-beta.N` / `-rc.N` | GitHub Prerelease archives, source on `dev` | Prereleases do not overwrite Homebrew or trigger stable auto-updates | Contributors & testers |

## Stable Installation (`main`)

We provide multiple installation methods for the stable channel, please choose the one that best suits your system environment:

<Tabs items={['Script Installation (Recommended)', 'Homebrew (macOS / Linux)', 'Build from Source']}>
  <Tab value="Script Installation (Recommended)">
    Run the following one-click installation script in the Linux or macOS terminal:
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AimAI-Labs/mihosh/refs/heads/main/install.sh | bash
    ```
  </Tab>
  <Tab value="Homebrew (macOS / Linux)">
    If you use Homebrew on macOS or Linux, install Mihosh with:
    ```bash
    brew tap AimAI-Labs/mihosh https://github.com/AimAI-Labs/mihosh
    brew trust AimAI-Labs/mihosh # Required on Homebrew 6+
    brew install AimAI-Labs/mihosh/mihosh
    ```
  </Tab>
  <Tab value="Build from Source">
    Requires Go 1.25+ installed on your system:
    ```bash
    git clone --branch main https://github.com/AimAI-Labs/mihosh.git
    cd mihosh
    make build
    # The compiled binary file is located in the current directory as mihosh
    ```
  </Tab>
</Tabs>

## Development & Prerelease Installation (`dev`)

If you want to try upcoming features or test prerelease builds (`vX.Y.Z-rc.N`, `-beta.N`, `-alpha.N`), use one of the following options:

1. **Download a prerelease archive:** Pick a prerelease tag from [GitHub Releases](https://github.com/AimAI-Labs/mihosh/releases), extract the archive for your OS/architecture, and install the `mihosh` binary into your `PATH`.
2. **Build from the `dev` branch** (requires Go 1.25+):
   ```bash
   git clone --branch dev https://github.com/AimAI-Labs/mihosh.git
   cd mihosh
   make build
   # The compiled binary file is located in the current directory as mihosh
   ```

## Verify Installation

After the installation is complete, you can verify whether the installation was successful using the following command:

```bash
mihosh version
```

## Uninstall

Mihosh includes a built-in one-click uninstaller that stops managed cores/services, cleans shell proxy hooks, and optionally preserves your configuration:

```bash
# Interactive uninstall (prompts to confirm and choose whether to keep config)
mihosh uninstall

# Unattended uninstall while keeping ~/.mihosh (or $MIHOSH_CONFIG_DIR)
mihosh uninstall --yes --keep-config
```

You can also press `u` on the **Settings** page in the TUI to uninstall with a confirmation modal. For Homebrew installations, run `brew uninstall mihosh` after cleaning configs/hooks.
