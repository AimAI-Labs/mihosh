Mihosh supports Linux and macOS systems (amd64 and arm64 architectures).

## Installation Methods

We provide multiple installation methods, please choose the one that best suits your system environment:

<Tabs items={['Script Installation (Recommended)', 'Homebrew (macOS)', 'Build from Source']}>
  <Tab value="Script Installation (Recommended)">
    Run the following one-click installation script in the Linux or macOS terminal:
    ```bash
    curl -fsSL https://raw.githubusercontent.com/AimAI-Labs/mihosh/refs/heads/main/install.sh | bash
    ```
  </Tab>
  <Tab value="Homebrew (macOS)">
    If you are a macOS user and use the Homebrew package manager, you can install it via the following commands:
    ```bash
    brew tap AimAI-Labs/mihosh https://github.com/AimAI-Labs/mihosh
    brew install mihosh
    ```
  </Tab>
  <Tab value="Build from Source">
    Requires Go 1.25+ installed on your system:
    ```bash
    git clone https://github.com/AimAI-Labs/mihosh.git
    cd mihosh
    make build
    # The compiled binary file is located in the current directory as mihosh
    ```
  </Tab>
</Tabs>

## Verify Installation

After the installation is complete, you can verify whether the installation was successful using the following command:

```bash
mihosh version
```
