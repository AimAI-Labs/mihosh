Mihosh 提供了一套全局及局部快捷键，以确保你在终端下能高效操作。

## 全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Tab` / `Shift+Tab` | 切换至 下一页 / 上一页 |
| `q` / `Ctrl+C` | 退出程序 |
| `/` | 打开搜索/过滤框 |
| `Esc` | 关闭当前弹窗或取消当前操作 |
| `?` | 切换显示帮助覆盖层 (Help Overlay) |
| `r` | 刷新当前页面数据 |

各页面在底层还可能会有特定的快捷操作（如在连接页使用按键关闭连接），可以在界面底部的帮助栏或通过 `?` 呼出快捷键参考查看。
