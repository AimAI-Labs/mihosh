Mihosh provides a set of global and local shortcuts to ensure you can operate efficiently in the terminal.

## Global Shortcuts

| Shortcut | Function |
| --- | --- |
| `Tab` / `Shift+Tab` | Switch to Next / Previous Page |
| `q` / `Ctrl+C` | Exit program |
| `/` | Open search/filter box |
| `Esc` | Close the current modal or cancel the current operation |
| `?` | Toggle the Help Overlay |
| `r` | Refresh current page data |

Each page may also have specific contextual shortcut operations at the bottom level (like pressing keys to close a connection on the connections page). You can view these in the help bar at the bottom or by pressing `?` to invoke the shortcut reference overlay.
