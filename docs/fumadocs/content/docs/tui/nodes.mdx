## 特性

- **双面板布局**：在宽屏模式下，左侧/上方为代理组（策略组）列表，右侧/下方为节点列表。
- **模式切换**：顶部的模式切换栏允许你在 **规则**、**全局** 和 **直连** 模式之间快速切换。
- **延迟测试**：点击底部状态栏的延迟指示器，或使用相应的快捷键，即可测试节点的延迟。
- **状态指示灯**：每个节点左侧的圆点表示其状态：
  - 🟢 绿色：延迟 < 100ms
  - 🟡 黄色：延迟 100-300ms
  - 🔴 红色：延迟 > 300ms
- **特殊节点**：
  - `REJECT`：以红色显示。
  - `DIRECT`：以灰色显示。

## 快捷操作

在节点管理页面中，你可以使用以下快捷键进行高效操作：

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` (或 `k` / `j`) | 在代理组或节点列表中上下移动选中项 |
| `←` / `→` (或 `h` / `l`) | 在宽屏模式下，左右切换焦点面板（代理组面板与节点面板） |
| `Enter` | 将当前代理组的出口切换为选中的节点 |
| `t` | 测试当前选中节点的延迟 |
| `T` | 批量测试当前选中代理组内所有节点的延迟 |
| `m` | 快速切换代理模式（规则 / 全局 / 直连） |
| `/` | 搜索或过滤当前列表中的节点 |

> **提示**：除了快捷键外，Mihosh 也支持鼠标操作。你可以直接通过鼠标点击选中节点，双击完成节点切换，或点击状态栏相应按钮执行测试与模式切换等操作。
