mihosh provides a feature-rich Terminal User Interface (TUI), allowing you to intuitively manage the mihomo proxy core directly from your terminal.

## Starting the TUI

Simply run the `mihosh` command to start the TUI, without any additional arguments:

```bash
mihosh
```

## Interface Layout

The TUI is composed of three main areas:

### Top Navigation Bar

The top navigation bar contains **6 function tabs** and a **Help** entry, each corresponding to different management functions.

### Main Content Area

The central area displays the specific content of the currently selected tab. Different pages offer varying interaction methods and information displays.

### Bottom Status Bar

The bottom status bar displays real-time system information:

- **Node Latency** — Information about the currently connected node
- **Connection Status** — Connection status indicator with the mihomo core
- **Upload Speed** — Current upload traffic rate
- **Download Speed** — Current download traffic rate
- **Memory Usage** — Mihomo core's memory consumption

## Page Navigation

You can switch between different pages using:

| Action | Description |
| --- | --- |
| `Tab` | Switch to the next page |
| `Shift+Tab` | Switch to the previous page |

## Responsive Layout

The TUI supports a responsive layout, automatically adjusting the display based on your terminal window width:

- **Widescreen Mode** (width ≥ 100 columns): Utilizes a dual-panel layout side-by-side, fully leveraging screen space.
- **Narrow Mode** (width < 100 columns): Uses a single-column stacked layout, optimized for smaller terminal windows.

<Callout type="info">
It is recommended to use a terminal window with a width of at least 100 columns for the best experience.
</Callout>
