mihosh 提供了一个功能丰富的终端用户界面（TUI），让你可以在终端中直观地管理 mihomo 代理核心。

## 启动 TUI

直接运行 `mihosh` 命令即可启动 TUI 界面，无需任何额外参数：

```bash
mihosh
```

TUI 界面由三个主要区域组成：

### 顶部导航栏

顶部导航栏包含 **6 个功能页签** 和 **帮助（Help）** 入口，分别对应不同的管理功能。

### 页面内容区

中间的主要区域用于显示当前选中页签的具体内容。不同页面提供不同的交互方式和信息展示。

### 底部状态栏

底部状态栏实时展示以下系统信息：

- **节点延时** — 显示当前连接节点的信息（规则、节点、延时）
- **连接状态** — 与 mihomo 核心的连接状态指示
- **上传速度** — 当前上传流量速率
- **下载速度** — 当前下载流量速率
- **内存占用** — mihomo 核心的内存使用情况
- **内存占用** — mihomo 核心的内存使用情况


## 页面导航

你可以通过以下方式在不同页面之间切换：

| 操作 | 说明 |
| --- | --- |
| `Tab` | 切换到下一个页面 |
| `Shift+Tab` | 切换到上一个页面 |

## 自动刷新

顶部导航栏的「自动刷新」倒计时显示距离下一次同步还有多久。Mihosh 定时从已连接的 Mihomo 读取节点列表、策略组、生效节点和代理模式。你在另一个客户端切换节点或「规则／全局／直连」模式时，节点页会跟上。查询成功后会短暂显示 `✔`。检测到策略组、组内节点、生效节点或模式变化时，还会显示同步提示。

可以在「设置 → 自动刷新(秒)」调整间隔，也可以运行 `mihosh config set auto-refresh-interval 5`。默认间隔为 5 秒，设为 `0` 可关闭定时查询。

连接 Mihomo 就绪时，Mihosh 会预加载节点、连接、规则、订阅和 Core 页的数据。开启定时查询时，下一秒还会再同步一次节点数据。点击导航页签会刷新该页，再次点击当前页签也会刷新。

验证自动同步时，让 TUI 停在节点页。在另一个连接同一内核的终端中，对可手动选择节点的策略组运行 `mihosh select "组名" "另一个节点名"`。等待下一轮倒计时结束，观察策略组显示的生效节点，验证后切回原节点。延迟数值更新后，按延迟排序的列表可能要到下一轮才调整顺序。

## 响应式布局

TUI 界面支持响应式布局，会根据终端窗口的宽度自动调整显示方式：

- **宽屏模式**（终端宽度 ≥ 100 列）：采用左右并排的双面板布局，充分利用屏幕空间
- **窄屏模式**（终端宽度 < 100 列）：采用上下堆叠的单列布局，适配较小的终端窗口

<Callout type="info">
建议使用宽度不小于 100 列的终端窗口以获得最佳体验。
</Callout>
