mihosh 提供了一个功能丰富的终端用户界面（TUI），让你可以在终端中直观地管理 mihomo 代理核心。

## 启动 TUI

直接运行 `mihosh` 命令即可启动 TUI 界面，无需任何额外参数：

```bash
mihosh
```

## 界面布局

TUI 界面由三个主要区域组成：

### 顶部导航栏

顶部导航栏包含 **6 个功能页签** 和 **帮助（Help）** 入口，分别对应不同的管理功能。

### 页面内容区

中间的主要区域用于显示当前选中页签的具体内容。不同页面提供不同的交互方式和信息展示。

### 底部状态栏

底部状态栏实时展示以下系统信息：

- **节点延时** — 显示当前连接节点的信息（规则、节点、延时）
- **连接状态** — 与 mihomo 核心的连接状态指示
- **上传速度** — 当前上传流量速率
- **下载速度** — 当前下载流量速率
- **内存占用** — mihomo 核心的内存使用情况
- **内存占用** — mihomo 核心的内存使用情况


## 页面导航

你可以通过以下方式在不同页面之间切换：

| 操作 | 说明 |
| --- | --- |
| `Tab` | 切换到下一个页面 |
| `Shift+Tab` | 切换到上一个页面 |

## 响应式布局

TUI 界面支持响应式布局，会根据终端窗口的宽度自动调整显示方式：

- **宽屏模式**（终端宽度 ≥ 100 列）：采用左右并排的双面板布局，充分利用屏幕空间
- **窄屏模式**（终端宽度 < 100 列）：采用上下堆叠的单列布局，适配较小的终端窗口

<Callout type="info">
建议使用宽度不小于 100 列的终端窗口以获得最佳体验。
</Callout>
