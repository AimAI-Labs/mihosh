## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Move focus up and down between different setting items |
| `Enter` | Expand dropdown boxes, toggle switches, or enter sub-settings |

## Configurable Items

- **Theme Switching**: Supports instant preview and switching of built-in terminal color themes (e.g., `tokyo-night`, `catppuccin`, `gruvbox`, `nord`, `dracula`).
- **Language Switching**: Dynamically switch the interface language (Supports `auto`, `en-US`, `zh-CN`).
- **System Status Overview**: The bottom of the page usually displays the tool's current version, build information, and a core runtime status overview.
