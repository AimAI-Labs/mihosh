title: 设置
description: 在 TUI 中修改配置
---

设置页面（快捷键 `6`）允许你直接在界面中修改 Mihosh 的运行配置及偏好设置，而无需手动编辑 `config.yaml`。

## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` (或 `k` / `j`) | 在不同的设置项之间上下移动焦点 |
| `Enter` (或 `Space`) | 展开下拉选择框、切换开关 (Toggle) 或进入设置子项 |
| `s` | 立即保存当前所有更改到磁盘的配置文件中 |

## 可配置项

- **主题切换**：支持即时预览并切换内置的终端色彩主题（如 `tokyo-night`, `catppuccin`, `gruvbox`, `nord`, `dracula` 等）。
- **语言切换**：动态切换界面语言（支持 `auto`, `en-US`, `zh-CN`）。
- **系统状态总览**：页面底部通常会显示当前工具的版本、构建信息以及核心的运行状态概览。
