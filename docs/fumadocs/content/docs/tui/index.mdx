mihosh provides a feature-rich Terminal User Interface (TUI), allowing you to intuitively manage the mihomo proxy core directly from your terminal.

## Starting the TUI

Simply run the `mihosh` command to start the TUI, without any additional arguments:

```bash
mihosh
```

## Interface Layout

The TUI is composed of three main areas:

### Top Navigation Bar

The top navigation bar contains **6 function tabs** and a **Help** entry, each corresponding to different management functions.

### Notifications

Notifications appear between the main navigation and the current page tabs. Text color distinguishes information, success, warnings, and errors. Click an error to view its details.

### Main Content Area

The central area displays the specific content of the currently selected tab. Different pages offer varying interaction methods and information displays.

### Bottom Status Bar

The bottom status bar displays real-time system information:

- **Node Latency** — Information about the currently connected node
- **Upload Speed** — Current upload traffic rate
- **Download Speed** — Current download traffic rate
- **Memory Usage** — Mihomo core's memory consumption

## Page Navigation

You can switch between different pages using:

| Action | Description |
| --- | --- |
| `Tab` | Switch to the next page |
| `Shift+Tab` | Switch to the previous page |

## Auto-refresh

The **Auto refresh** countdown in the top navigation shows when Mihosh will next read the node list, proxy groups, active nodes and proxy mode from the connected Mihomo core. This keeps the Nodes page in sync when another client changes a selection or switches between Rule, Global and Direct modes. After a successful read, the countdown briefly shows `✔`. Mihosh shows a sync notice when it detects changes to the groups, their members, their active nodes or the mode.

Set the interval in **Settings → Auto Refresh(s)** or with `mihosh config set auto-refresh-interval 5`. The default is five seconds. Set it to `0` to turn off periodic polling.

When a connection to Mihomo becomes ready, Mihosh preloads data for the Nodes, Connections, Rules, Subscriptions and Core pages. When periodic polling is enabled, the next tick reads the node data again. Clicking a navigation tab refreshes that page, including when you click the tab that is already open.

To check periodic sync, leave the TUI on the Nodes page. In another terminal connected to the same core, run `mihosh select "Group name" "Another node"` for a group that allows manual selection. Watch the group's active node after the next countdown, then restore the original node. Updated latency values can appear one cycle before latency-based ordering catches up.

## Responsive Layout

The TUI supports a responsive layout, automatically adjusting the display based on your terminal window width:

- **Widescreen Mode** (width ≥ 100 columns): Utilizes a dual-panel layout side-by-side, fully leveraging screen space.
- **Narrow Mode** (width < 100 columns): Uses a single-column stacked layout, optimized for smaller terminal windows.

<Callout type="info">
It is recommended to use a terminal window with a width of at least 100 columns for the best experience.
</Callout>
