## Shortcuts

To quickly locate issues within massive logs, you can use the following shortcuts:

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Scroll the log list |
| `Enter` | Pop up full JSON details for the currently selected log (supports mouse scrolling) |
| `c` | Clear all historical logs from the screen |
| `/` | Open the keyword search/filter box to highlight log lines containing specific text |

## Interface Features

- **Color Coding**: Different log levels (e.g., Info, Warning, Error) are highlighted with different colors for quick visual localization.
- **JSON Details View**: Many logs contain deeply nested structural data. Pressing `Enter` brings up a modal that elegantly presents complex internal information.
