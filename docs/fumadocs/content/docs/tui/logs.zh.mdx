## 快捷操作

为了方便在海量日志中快速定位问题，你可以使用以下快捷操作：

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 滚动日志列表 |
| `Enter` | 弹窗展示当前选中日志的完整 JSON 详情（支持鼠标滚动查看） |
| `c` | 清空屏幕上的所有历史日志 |
| `/` | 开启关键词搜索/过滤框，高亮包含特定文本的日志行 |

## 界面特性

- **颜色编码**：不同的日志级别（如 Info, Warning, Error）使用不同的颜色高亮，便于快速视觉定位。
- **JSON 详情视图**：许多日志包含深层结构数据，按下 `Enter` 后的弹窗可以将复杂的内部信息优雅地呈现出来。
