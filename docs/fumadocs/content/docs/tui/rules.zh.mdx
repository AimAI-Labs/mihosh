## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 滚动浏览当前的所有分流规则 |
| `/` | 打开多关键词搜索框，输入关键字对规则进行复杂过滤 |
| `t` | 展开或收起搜索框下方的规则类型 |
| `n` | 添加规则 |
| `Enter` | 编辑选中规则 |
| `d` | 确认删除选中规则 |

点击类型即可筛选，也可用 `←` / `→` 移动焦点并按空格切换。当前配置没有的类型显示为灰色。支持同时选择多个类型，也可和文本搜索组合使用。筛选栏可见时按 `Esc` 清除类型筛选。

Mihosh 将这些变更记录到 `merge.yaml` 的 `rule-edits` 中并应用到内核。新增规则按所选位置插入。编辑和删除按原规则内容匹配，刷新订阅后，只要原规则仍存在，覆写就会继续生效。源订阅快照保持原样。修改远程内核规则需要先激活订阅，变更在远端内存中生效。

## 界面特性

- **全局规则浏览**：分页查看当前配置生效的所有代理规则。
- **动态规则提供者 (Rule Provider)**：查看和管理远程获取的规则提供者状态（如更新时间、包含规则数）。
