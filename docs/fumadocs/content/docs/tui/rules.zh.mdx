## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 滚动浏览当前的所有分流规则 |
| `/` | 打开多关键词搜索框，输入关键字对规则进行复杂过滤 |
| `t` | 展开或收起搜索框下方的规则类型 |
| `n` | 添加规则 |
| `Enter` | 编辑选中规则 |
| `d` | 确认删除选中规则 |

在添加或编辑表单中，将焦点移到「类型」，按空格搜索。匹配忽略大小写。用方向键或鼠标选择已有类型，也可以确认输入的自定义名称。

点击类型即可筛选，也可用 `←` / `→` 移动焦点并按空格切换。当前配置没有的类型显示为灰色。支持同时选择多个类型，也可和文本搜索组合使用。筛选栏可见时按 `Esc` 清除类型筛选。

Mihosh 将规则的增删改记录在 `rule-edits.yaml`，生成配置时应用。源订阅快照和 `merge.yaml` 保持原样。订阅刷新后使用最新规则，编辑和删除继续匹配仍存在的原规则。修改远程内核规则需要先激活订阅，变更在远端内存中生效。

## 界面特性

- **全局规则浏览**：分页查看当前配置生效的所有代理规则。
- **动态规则提供者 (Rule Provider)**：查看和管理远程获取的规则提供者状态（如更新时间、包含规则数）。
