## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 滚动浏览当前的所有分流规则 |
| `/` | 打开多关键词搜索框，输入关键字对规则进行复杂过滤 |
| `t` | 展开或收起搜索框下方的规则类型 |
| `n` | 添加规则 |
| `Enter` | 编辑选中规则 |
| `d` | 确认删除选中规则 |

在添加或编辑表单中，将焦点移到「类型」，按空格搜索。匹配忽略大小写。用方向键或鼠标选择已有类型，也可以确认输入的自定义名称。

点击类型即可筛选，也可用 `←` / `→` 移动焦点并按空格切换。当前配置没有的类型显示为灰色。支持同时选择多个类型，也可和文本搜索组合使用。筛选栏可见时按 `Esc` 清除类型筛选。

规则页的增删改保存在 `rule-edits.yaml`。修改远程内核规则需要先激活订阅，变更在远端内存中生效。

## 规则冲突与最佳实践

Mihosh 先将 `merge.yaml` 应用到订阅，再应用保存的规则变更。若 `merge.yaml` 定义了 `rules`，该列表会整体替换订阅规则。新增规则按保存的序号插入。修改和删除按原规则定位，原规则在当前列表中找不到时会跳过这项变更。

在规则模式下，Mihomo 从上往下匹配，通常采用首条命中的策略。把 `DOMAIN,login.example.com,DIRECT` 放在 `DOMAIN-SUFFIX,example.com,REJECT` 上方，登录域名就会优先直连。[Mihomo 规则优先级](https://wiki.metacubex.one/config/rules/#优先级)

- **跟随订阅更新时，用规则页维护少量自定义规则。** 有意接管整张规则表时，再在 `merge.yaml` 写入 `rules`。
- **需要改策略时，直接编辑已有规则。** 添加例外时，把精确规则放在会覆盖它的宽泛规则前面，将兜底的 `MATCH` 放在最后。
- **刷新或切换订阅后，检查最终顺序。** 在订阅页按 `c` 打开「激活文件」或差异。订阅规则的数量或顺序变化后，新增规则和其他规则的相对位置可能改变。[订阅管理](/docs/tui/subscriptions)

## 界面特性

- **全局规则浏览**：分页查看当前配置生效的所有代理规则。
- **动态规则提供者 (Rule Provider)**：查看和管理远程获取的规则提供者状态（如更新时间、包含规则数）。
