## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Move selection up or down in the subscription or rule-set list |
| `u` | Immediately pull and update the currently selected subscription or rule-set |
| `m` | Open override settings |
| `c` | View configuration file |
| `n` | Add a new rule |
| `e` | Edit rule |
| `d` | Delete rule |
| `/` | Search for a specific subscription name |

## Interface Features

- **Unified Management**: Manage both Proxy Providers and Rule Providers in one place.
- **Real-time Progress Feedback**: While updating, the right panel will display update progress, time taken, and any errors that occurred.
