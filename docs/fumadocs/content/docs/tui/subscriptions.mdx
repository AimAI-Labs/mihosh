## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 在订阅或规则集列表中上下移动选中项 |
| `u` | 立即拉取并更新当前选中的订阅或规则集 |
| `m` | 打开覆写设置 |
| `c` | 查看配置文件 |
| `n` | 添加新规则 |
| `e` | 编辑规则 |
| `d` | 删除规则 |
| `/` | 搜索特定的订阅名称 |

## 界面特性

- **配置与规则集统管**：不仅可以管理节点订阅 (Proxy Provider)，也可以管理分流规则的订阅 (Rule Provider)。
- **实时进度反馈**：在执行更新操作时，右侧面板会展示更新进度、拉取耗时以及是否有错误发生。
