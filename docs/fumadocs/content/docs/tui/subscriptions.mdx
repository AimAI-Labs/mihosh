## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Move selection up or down in the subscription or rule-set list |
| `u` | Immediately pull and update the currently selected subscription or rule-set |
| `m` | Open override settings |
| `c` | View configuration file |
| `n` | Add a new rule |
| `e` | Edit rule |
| `d` | Delete rule |
| `/` | Search for a specific subscription name |

## Local files and previews

Place `.yaml` or `.yml` profiles in `raw/` under the Mihosh configuration root. Mihosh imports them at startup and when you open or refresh the Subscriptions page. Each imported profile keeps a snapshot. Use `u` to refresh it after editing the source. To prevent a deleted subscription from being imported again, move its source out of `raw/`.

Press `c` to choose the source snapshot, the activated configuration generated with `merge.yaml`, or a diff. The source and activated views open read-only temporary copies in Vim and use One Dark Pro for YAML highlighting. Make sure `vim` is on PATH. The copies are removed when Vim exits. The views also work for inactive subscriptions. The diff uses side-by-side panes from 100 columns and stacked panes in narrower terminals.

## Interface Features

- **Unified Management**: Manage both Proxy Providers and Rule Providers in one place.
- **Real-time Progress Feedback**: While updating, the right panel will display update progress, time taken, and any errors that occurred.
