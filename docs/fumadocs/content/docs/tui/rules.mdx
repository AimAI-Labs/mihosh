## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Scroll through all currently active routing rules |
| `/` | Open the multi-keyword search box for complex rule filtering |
| `t` | Show or hide the rule types below search |
| `n` | Add a rule |
| `Enter` | Edit the selected rule |
| `d` | Confirm deletion of the selected rule |

Click a type to filter the list, or use `←` / `→` and `Space`. Types absent from the current configuration appear in gray. You can select several types and combine them with text search. Press `Esc` to clear the type filter when its row is visible.

Mihosh saves the edited list under Mihomo's native `rules` field in `merge.yaml` and applies it to the core. While the field is present, it replaces the subscription's rule list even after refreshing or switching sources. The source snapshot stays intact. Remote rule editing requires an active subscription and applies in memory on the remote core.

## Interface Features

- **Global Rule Browsing**: Paginated view of all proxy rules currently taking effect.
- **Dynamic Rule Provider**: View and manage the status of remotely fetched rule providers (such as update time, total rule count).
