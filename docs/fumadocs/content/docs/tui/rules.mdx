## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Scroll through all currently active routing rules |
| `/` | Open the multi-keyword search box for complex rule filtering |
| `Enter` | View detailed information on the policy group or node associated with the selected rule |

## Interface Features

- **Global Rule Browsing**: Paginated view of all proxy rules currently taking effect.
- **Dynamic Rule Provider**: View and manage the status of remotely fetched rule providers (such as update time, total rule count).
