## Shortcuts

| Shortcut | Description |
| --- | --- |
| `↑` / `↓` | Scroll through all currently active routing rules |
| `/` | Open the multi-keyword search box for complex rule filtering |
| `n` | Add a rule |
| `Enter` | Edit the selected rule |
| `d` | Confirm deletion of the selected rule |

Mihosh records these changes under `rule-edits` in `merge.yaml` and applies them to the core. Additions use the selected position. Edits and deletions match the original rule by its content, so they continue to apply when that rule is still present after a subscription refresh. The subscription snapshot stays intact. Remote rule editing requires an active subscription and applies in memory on the remote core.

## Interface Features

- **Global Rule Browsing**: Paginated view of all proxy rules currently taking effect.
- **Dynamic Rule Provider**: View and manage the status of remotely fetched rule providers (such as update time, total rule count).
