## Shortcuts

In the connection monitor page, you can use the following shortcuts to manage active connections:

| Shortcut | Description |
| --- | --- |
| `↑` / `↓`  | Scroll up/down the active connection or history list |
| `x` | Forcefully close the currently selected active connection |
| `X` | Forcefully close ALL active connections |
| `s` | Toggle list sorting methods (e.g., sort by traffic, sort by download speed) |
| `/` | Search or filter connections (e.g., filter by target domain) |

> **Tip**: All connection data is updated in real-time via WebSocket, no manual page refresh is required.
