## 快捷操作

在连接监控页面中，你可以使用以下快捷键来管理活动连接：

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓`  | 在活动连接或历史记录列表中上下滚动 |
| `x` | 强制关闭当前选中的活动连接 |
| `X` | 强制关闭所有活动连接 |
| `s` | 切换列表的排序方式（如按流量、按下载速度排序等） |
| `/` | 搜索或过滤连接（如按目标域名过滤） |

> **提示**：所有连接数据均通过 WebSocket 实时更新，无需手动刷新页面。
