## 快捷操作

| 快捷键 | 操作说明 |
| --- | --- |
| `↑` / `↓` | 在订阅或规则集列表中上下移动选中项 |
| `u` | 立即拉取并更新当前选中的订阅或规则集 |
| `m` | 打开覆写设置 |
| `c` | 查看配置文件 |
| `n` | 添加新规则 |
| `e` | 编辑规则 |
| `d` | 删除规则 |
| `/` | 搜索特定的订阅名称 |

## 本地文件与预览

将 `.yaml` 或 `.yml` 配置放到 Mihosh 配置目录下的 `raw/`。启动、打开订阅页或刷新订阅页时会自动导入。导入时保存一份快照，源文件修改后可按 `u` 更新。删除订阅后，若要取消后续自动导入，可将源文件移出 `raw/`。

按 `c` 选择源文件快照、与 `merge.yaml` 合并生成的激活文件或差异。源文件和激活文件使用 Vim 打开只读临时副本，并使用 One Dark Pro 配色高亮 YAML。请确保 `vim` 在 PATH 中。未激活的订阅也可查看，退出 Vim 后会清理临时副本。差异在 100 列及以上并排展示，窄屏上下展示。

在差异视图中按 `o` 或点击「差异选项」，可分别忽略缩进、其他空白和不可见字符（如 BOM、零宽字符）。选项影响比较结果，两栏继续显示源文件和生成配置的行内容。

## 界面特性

- **配置与规则集统管**：不仅可以管理节点订阅 (Proxy Provider)，也可以管理分流规则的订阅 (Rule Provider)。
- **实时进度反馈**：在执行更新操作时，右侧面板会展示更新进度、拉取耗时以及是否有错误发生。
